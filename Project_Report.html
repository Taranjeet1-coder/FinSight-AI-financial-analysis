ABSTRACT

This report presents a comprehensive comparative financial analysis of Bitcoin (BTC), Gold, and the S&P 500 Index, covering approximately 2,800 daily observations from mid-2014 through 2025. The study is structured in nine analytical modules progressing from data engineering through portfolio optimization and interactive dashboard deployment.

The analysis employs logarithmic return computation, GARCH(1,1) volatility modeling, Value-at-Risk estimation, machine learning classification (Random Forest, XGBoost), deep learning forecasting (LSTM, GRU), fuzzy logic risk scoring, and Genetic Algorithm-based portfolio optimization. Key findings reveal Bitcoin's extreme kurtosis (13.08) and volatility (~72% annualised), Gold's role as a near-zero-correlated safe haven (r=0.02 with S&P 500), and classical machine learning outperforming deep learning for daily return prediction (Random Forest R²=0.22 vs LSTM R²=−0.18). The optimized portfolio allocating 56.3% Gold, 38.7% S&P 500, and 5.0% Bitcoin achieved a Sharpe ratio of 0.67 and returned +8.2% during the COVID-19 crash.

Keywords: Bitcoin, Gold, S&P 500, GARCH, VaR, Random Forest, LSTM, Fuzzy Logic, Genetic Algorithm, Portfolio Optimization, Efficient Frontier

CH 01Introduction & Problem Statement

The emergence of cryptocurrencies, particularly Bitcoin, has fundamentally disrupted the traditional investment paradigm. For centuries, Gold has served as the primary safe-haven asset and inflation hedge in investor portfolios. The S&P 500 has long represented the benchmark for equity market performance in the United States. The advent of Bitcoin—with its decentralized structure, fixed supply, and extreme volatility—raises critical questions about its role in a diversified portfolio.

This study addresses three core research questions:

  1. How do Bitcoin, Gold, and the S&P 500 compare statistically in terms of return, risk, and distributional properties?
  2. What predictive models best capture the behaviour of these assets across market regimes?
  3. What optimal portfolio allocation across these three asset classes maximises risk-adjusted returns?
📌 Scope Statement This report covers 11 years of daily data (mid-2014 to 2025) across Bitcoin (BTC-USD), Gold (GLD ETF), the S&P 500 (^GSPC), and VIX (^VIX) as a market sentiment proxy. All analysis was conducted using Python with the results deployed in an interactive Streamlit dashboard.

CH 04Risk & Volatility Analysis

4.1 GARCH(1,1) Volatility Modeling

The Generalised Autoregressive Conditional Heteroskedasticity (GARCH) model was applied to Bitcoin's log returns to capture volatility clustering — the empirically observed phenomenon where high-volatility periods cluster together in time.

GARCH(1,1) Model Specification:
r_t = μ + ε_t, where ε_t = σ_t · z_t
σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}

Estimated Parameters (Bitcoin):
ω (Omega) = 0.0000021 → Long-run variance baseline
α (Alpha) = 0.142 → ARCH effect — shock impact
β (Beta) = 0.779 → GARCH persistence
α + β = 0.921 → Volatility persistence index
Log-Likelihood = 2,864.3

GARCH Conditional Volatility Over Time (%) — BTC vs S&P 500

⚡ Persistence Interpretation (α+β = 0.921) A persistence value above 0.9 indicates that volatility shocks take a very long time to dissipate. When Bitcoin's volatility spiked to ~110% during the COVID-19 crash (March 2020), the GARCH model predicts that elevated volatility persisted for several months afterward. This has direct implications for risk managers who must dynamically adjust portfolio weights during high-volatility regimes.

🔴 Honest Assessment — Why Deep Learning Failed Negative R² values indicate that both LSTM and GRU performed worse than simply predicting the mean return every day. This is not a failure of implementation — it is a well-documented phenomenon in financial ML. Daily asset returns closely approximate a random walk process (efficient market hypothesis), meaning there is minimal autocorrelation structure for sequential models to exploit. Classical ML models with proper feature engineering outperform deep learning because they can leverage cross-sectional and volatility features rather than depending on autocorrelation in the return series.

CH 08Soft Computing

8.1 Fuzzy Logic Risk Scoring System

A Mamdani-type fuzzy inference system was designed to generate interpretable, rule-based risk signals from VIX levels and rolling volatility. Three input linguistic variables were defined — VIX (Low/Medium/High), Rolling Volatility (Low/Medium/High), and BTC Trend (Bearish/Neutral/Bullish) — producing a single output signal: BUY / HOLD / SELL.

Fuzzy Rule Base:
Rule 1: IF (VIX is LOW) AND (BTC_Trend is BULL) → Signal = BUY
Rule 2: IF (VIX is HIGH) OR (RollingVol > 0.05) → Signal = SELL
Rule 3: IF (VIX is MEDIUM) AND (BTC_Trend is NEUTRAL) → Signal = HOLD

Membership Functions: Trapezoidal (VIX), Triangular (Vol & Trend)
Defuzzification Method: Centroid

8.2 Genetic Algorithm Portfolio Optimization

A Genetic Algorithm (GA) was implemented to find the optimal portfolio weights that maximise the Sharpe Ratio — analogous to finding the maximum Sharpe point on the Efficient Frontier, but using evolutionary computation rather than gradient-based methods. This approach can navigate non-convex, multi-modal objective landscapes that challenge traditional optimizers.

Genetic Algorithm Parameters:
Population Size : 500 individuals
Generations : 1,000
Crossover Rate : 0.8 (uniform crossover)
Mutation Rate : 0.05 (Gaussian mutation)
Selection : Tournament selection (k=3)
Fitness Function : Sharpe Ratio = (Portfolio Return) / (Portfolio Volatility)
Constraints : Σ w_i = 1.0, w_i ≥ 0 (long-only, fully invested)

CH 12Conclusion & Future Scope

12.1 Conclusion

This study demonstrates that a mathematically rigorous, data-driven approach to portfolio construction across Bitcoin, Gold, and the S&P 500 yields measurably superior outcomes compared to any single-asset strategy or naive equal-weight allocation. The following conclusions are supported by the analysis:

  1. Asset classes are fundamentally different in risk profile. Bitcoin operates in a completely different volatility and kurtosis regime that requires special treatment in risk models.
  2. Classical ML outperforms deep learning for daily financial return prediction, due to the near-random-walk nature of daily returns.
  3. GARCH modeling is essential — static risk metrics fail to capture the persistence and clustering of volatility that characterises cryptocurrency markets.
  4. A 5% Bitcoin allocation is the mathematical sweet spot: it provides meaningful exposure to asymmetric upside while keeping portfolio-level drawdown manageable.
  5. Fuzzy Logic and Genetic Algorithms provide valuable, interpretable frameworks for risk management and optimization that complement black-box ML approaches.
  6. Diversification works. The optimized portfolio returned +8.2% during the COVID crash versus −6% for pure equities — a concrete demonstration of Markowitz's Modern Portfolio Theory in practice.
